# Battle Scissors

A 2D mobile canvas game prototype built around one mechanic: the player's fingers work a pair of scissors that snip whatever sits between the blades. Touch has two control modes (Settings on the title): **Hold** (default, easy: hold one finger to open, lift to snip) and **Pinch** (two fingers are the handles, a fast pinch snips).

## Running

Double-click `Play.bat`, or run:

```bash
node tools/serve.js
```

It serves on port 8000 on all interfaces, opens http://localhost:8000 (with `--open`), and prints a LAN address for testing on a phone on the same Wi-Fi. If 8000 is busy it moves up to the next free port (8001, 8002, ...). `python3 -m http.server` also works. ES modules don't load from `file://`, so opening `index.html` directly shows a "use Play.bat" message. Desktop controls (mouse, wheel, Space, A/D rotate, E = move slot 1, F = move slot 2, P/Esc = pause, R) are listed at the top of `index.html`. `?seed=1234` pins the run seed and `?level=fork` picks the level (the run report's replay link carries both). `?recipe=s,fork pin` plays a generated road (see Level generator below; `?world=snow` picks its look). `?waves=leaf:5,burr:2` is a dev override of a level's waves. `?lab=1` opens the playtest workbench (lab.js): everything unlocked in a sandbox, any road in any world's look, enemies on demand. The level lab, `/tools/level-lab.html` on the dev server, previews recipes.

Shared runtime state lives in exported objects (`state` in game.js, plus `input`, `view`, `weapon`, `cut`), because ES modules can't reassign each other's `let` bindings. `state` holds the mode, wave, HP, score, seed, stats, effect timers (`state.fx`), the road polylines (`state.paths`, one per route of the level), the thread balance, `heli` (SHRED's spin, one at a time), `moves` (the two move slots, plain objects with the same fields: `i`, `id` ('' / 'shred' / a Skill), `def`, `need`, `charge` 0..1, `armed`, `go`, `uses`, and the Skills' live fields `marksLeft`, `focusT`, `bannerT`, `laneT` / `lx0..ly1`, `sewing` / `sx..ey`), `thimble`, `stitches` (Basting's lines, pooled), `curls` (ribbon curls and Pinking trails, `kind`), `tut` (onboarding step), `run` (report counters), `events` (a 32-entry ring of one-off happenings for the renderer: `thread` pickups, `place`) and the entity pools (`enemies`, `frags`, `parts`, `labels`, `nums`, `pops`, `needles`, and `towers`, one per spot of the current level, rebuilt by `setLevel`; plus `critters` and `splats`, owned by critters.js): plain objects with an `on` flag and no methods. Each frame, `update()` calls `updateInput()` first, so snips resolve before timers and entities advance; then `draw(state)` paints.

**game.js contains no canvas calls. All drawing lives in render.js. This keeps a future Phaser/Godot port cheap.** (render.js calls the art helpers enemyArt.js, towerArt.js and weaponArt.js; game.js, input.js and scissors.js never draw.)

Seeds: every run gets `state.seed` (`Date.now()` by default; `?seed=1234` in the URL pins it for every run). Gameplay randomness uses mulberry32 streams from that seed: `rng.spawn` (enemy variation, and which route each enemy takes on a multi-route level; single-route levels draw nothing for it), `rng.hit` (shove chance), `rng.fx` (fragment bursts), `rng.critter` (critter schedule and lanes). They're separate so spawns don't depend on how many hits happened. Only purely visual sparkle (particles) may use `Math.random`. The seed shows in the debug panel and on the game-over card.

## Game flow

**Worlds.** The map is five worlds of ten levels (`docs/worlds.md`, the design contract; change it before the code): each a drawer or box in the house with its own look (`world`: meadow The Sewing Tray, denim The Mending Pile, autumn The Kitchen Drawer, night The Bedside Drawer, snow The Holiday Box), its own enemy, Pin and Skill, a mini boss on level 5 and the drawer's tool gone bad as the boss on level 10, which opens the next world. Level ids never change (saves key on them). World rules (`CONFIG.worldRules[world]`, game.js `worldRule()`): autumn's gusts (every `gustEverySec` a GUST banner and every enemy on the road jumps `gustU` forward over `gustSec`, Leaves `gustLeafMult` x; held, pulled, frozen or airborne ones don't), night's dark (the plate is dimmed outside pools of light: the painter's lanterns (`level().lights`), the Lamp Pin's ring, the heart pad `heartLightR`, every Pin `pinLightR`; an enemy outside every light is drawn at `darkAlpha` with no weak spot; `isLit()` is exported), snow's cold (the Ice Pin's slow `coldIceMult` weaker, burns `coldBurnMult` x longer, Brutes start with `coldArmor` armor layers).

`TITLE -> MAP | SETTINGS | level 0 (TUTORIAL -> MAP), MAP -> SELECT -> PLAYING -> WAVE_CLEAR (waveClearMs) -> PLAYING ... -> GAME_OVER`. On the title, PLAY opens the level MAP (tap a numbered patch; BACK returns to the title), which opens SELECT for the weapon (it names the level; START begins, BACK returns to the map); How to play replays level 0; the gear opens SETTINGS (touch controls Hold/Pinch, Sound, Vibration; BACK returns); the Sound icon toggles mute; the title's Shop tile opens the Shop (tabs: Scissors = the inventory, equip, upgrades, Sharpen and the pairs for sale; Moves = SHRED's tiers and skills to come; Style = cosmetics; BACK returns to the title); the Shop and Trophies also open from the map's top-left row, beside the Buttons balance. Random Quilt (title, once level 0 is cleared) and Custom Road are off the map: their weapon screen BACK, the results card's small button (Title) and the pause card lead to the title, not the map, and a quilt run's results offer NEW QUILT. Level 0 (TUTORIAL, see below) replaces the old text coach: PLAY opens it instead of the map until it has been cleared once. GAME_OVER covers both outcomes: losing (workshop HP hits 0) and winning (after the last entry in `CONFIG.waves`), shown with different headers. The card plays the results (results.js: stars, the Button tally by source, total, unlock reveal) and then shows one big button for the obvious next step (NEXT LEVEL on a win with a next patch, `nextLevelId()`, which crosses world boundaries, same weapon, straight into the level (main.js `playNext`; through the weapon screen when that level brings something new, `showLevelName`), only when `Save.reveals` is empty and no chest was readied, else TO THE MAP so the map plays the cards first; CONTINUE to the MAP on a win without a next level; TRY AGAIN on a loss) with the others small underneath (Map, Play again). Pause (`state.paused`, not a mode; `state.pauseCard` = `menu`, `pins` or `build` (the Pin picker: no card) picks which card shows): the ⏸ button, P/Esc, or hiding the tab during PLAYING / WAVE_CLEAR / TUTORIAL. `update()` returns immediately while paused (no input, timers, tweens or clock), event-driven hooks (taps, E, Space) are ignored, paused time is excluded from the run duration, and resuming re-arms snip detection. The pause card offers RESUME, Back to map, Sound on/off and Quit to title (leaving a run mid-way sends it as a `quit`). Send feedback lives in Settings only (plus the credits card). Quit to title, the game-over Reset (home) tile and the R key return to TITLE; START and Play Again call `startGame()` with the current weapon.

- Weapons live in `CONFIG.weapons`: SVG geometry (`viewW/viewH/pivotX/pivotY/bladeLen/maxOpenDeg`, taken from the art) plus gameplay (`reachFrac` = on-screen blade length as a fraction of screen height, `damageMult`, `openMs` = how long a held mouse button or Hold-mode finger takes to open it fully). `view.S = reachFrac * weaponScale * H / bladeLen`. Blade opening, cut-zone width and reach, and blade-contact size all come from the current weapon. `maxOpenDeg` is half the cut zone's angle at full open; `aimOffsetDeg + aimOffsetOpenDeg × open` turns the whole art so an off-centre gap lines up with the aim (Ratchet Pruners). `kind: 'slide'` (Cigar Cutter): no pivot or blade angle; the cut zone is a circle of radius `bladeLen` at the hole, graded from its centre; closing blades don't shove; the boss seam line runs across the hole; SHRED reaches `spinLen`; the weapon card shows Hole and "guillotine" instead of Reach and Spread.

- Waves come from the level file's `waves` (else `CONFIG.waves`): one array per wave of `[type, count, atSec]` entries, with group members spaced by the type's `gapMs`. A spawn waits if the enemy pool is full. If every enemy is dead mid-wave, the wave clock skips ahead so the next spawn is at most `emptyWaveWaitSec` away (group spacing is untouched, since the skip only happens while the board is empty). Dev only: `?waves=leaf:5,burr:2;moth:4@3` replaces a level's waves (game.js `levelWaves`; not level 0).
- Enemy types live in `CONFIG.enemyTypes`, one or two new per world (`docs/worlds.md`): scrap (groups, 1 HP), bolster (3 HP), runner (small and fast, 1 HP; from 1-3), brute (6 HP plus armor; from 1-6), leaf (world 3; `light`, `driftPx` / `driftSec`: drifts side to side across the road, a gust carries it `gustLeafMult` x), burr (world 3; `tipImmune`: a graded hit in the tip half of the blades does nothing, "SPIKES!"; pivot-half hits, fire, needles and SHRED work), moth (world 4; `hopEverySec` / `hopU` / `hopSec`: lifts off and lands further along; while `e.air` nothing touches it: snips, blade contact, Pins, needles, Magnet pulls, SHRED, gusts, captures; drawn as a shadow on the road with the moth small and high), beetle (the Button Beetle, 10 HP, world 4: `fireImmune`, `flat` = no weak spot, every snip does tip damage; `ringExecute` = a Cigar Cutter snip with its centre in the hole kills it outright), snowball (world 5; `growHpPerSec` / `growRPerSec` / `growMax`: grows while it rolls, kill it early), icicle (world 5; runner-fast, `iceImmune`, fire does `iceFireMult` x), and the bosses and mini bosses (below). Snip damage is graded and must stay that way: `damageAtPivot` (2) down to `damageAtTip` (1), times the opening power (`powerAtMinOpen`..1), times `weakDamageMult` for a nick. So base HP equals snips needed at worst (a full-open snip at the tips). Enemy HP scales by wave and by place (game.js `hpScale`): `1 + hpPerWave × (wave − 1) + levelHp × (hpPerWorld × (world − 1) + hpPerLevel × (n − 1))` (the type's `levelHp`: Bolster, Brute 1; Scrap, Beetle 0.5; Runner 0; Random Quilt / Custom Road count as world `hpOffMapWorld` level `hpOffMapLevel`; the tutorial's wave 0 uses base HP). Enemy ranks (`CONFIG.enemyRanks`, game.js `rankMix` / `drawRank`, `e.rank` 1..3): from global level `fromLevel` a wave spawn (not a boss, its escorts or level 0) may come as rank 2 or 3 of its type: its own colours (`enemyRanks.colors`, a sprite per rank in enemyArt.js), `hpMult` more HP, a touch faster (`speedMult`), more score (`scoreMult`; thread is the same). The mix grows per global level and per wave: rank 2s fill in through worlds 1-2, rank 3s through worlds 3-5.
- Brute armor: the first snip clangs for 0 damage unless `e.slowed` is true (Ice Pin aura, or a recent Helicopter hit).
- Thread (tower currency, in-level only, gone when the level ends): `startThread`, +`threadPerKill` per kill (a level file may set its own `startThread` / `threadPerKill`), +`threadPerLeak` when an enemy reaches the workshop, +30 per squished silverfish. Each map level's kill yield is trimmed so squishing every critter gives the pre-critter total and squishing none leaves it 60-120 short (`node tools/wavesheet.js`).
- Critters (`CONFIG.critters`, src/critters.js): bonus targets only a manual snip hits (not SHRED's spin or its final snap; Pins never see them, they aren't in `state.enemies`). No HP, not in waves, never reach the workshop, no penalty for escaping. Per level cap (`critters: { silverfish: n }`: World 1 2, World 2 3, World 3 4). Seeded (`rng.critter`), each due at a random moment of a boss-free wave's window (after `minWaveSec`); a due one waits while fewer than `minEnemies` are on screen or a boss seam is warning/open. Silverfish: crosses edge to edge in `crossSec` (2.3s) on a wobbling line off the road; blades *opening* within `skitterPx` make it turn a random `skitterMinDeg`..`skitterMaxDeg` off its line, toward the middle of the screen `skitterInward` of the time (the other way only if the burst stays on screen), and burst for `skitterSec` (once per crossing); a squish = 30 thread, the `squish` sound, a splat fading over `splatSec`, a gold "+30" flying to the counter. L02 (`critterIntro`) scripts its first one into wave 1's first lull (the wave clock holds while it crosses), and its third star is `starRules.critters` (every silverfish that came was squished). Run reports carry `critterKills` / `critterSpawns`; `Save.critterKills` counts all runs for the "Squish 25" achievement.
- Buttons (meta currency, `CONFIG.meta`, meta.js; never converted to or from thread): the wage on every win, floor(score/100) capped at `scoreCapBase + scoreCapPerLevel × the global level number` (1-1 9, 5-10 58; replays pay it every time, so income never runs out; Random Quilt pays it as level `hpOffMapLevel`; `bonusPaid` keeps the level's best for the card); stars 10/15/25 the first time each is earned; achievements (achievements.js) once each; a world chest (five, one per world: three-star every level of a world, then tap it on the map: 100 + a cosmetic); stars, achievements and chests only on the map. Spent in the Shop (shop.js: new things only) on the Shop scissors (200-500 each, `CONFIG.weapons[id].shop`) and cosmetics; in the Sewing Box (sewingBox.js, tabs by armory.js: what you hold) on upgrades 150/300/600 per weapon (T1 +15% reach, T2 +20% close speed, T3 the weapon's `signature` stat +30%: Split Enders angle, War Nippers damage, Scrap Snippers crit (`critZone`/`critMult`), Ratchet Pruners jaw hold (`holdSec`: its hits hold regular enemies still), Cigar Cutter ring (`ringScale`), Kitchen Shears notch (`pivotZone`: a graded snip with a Burr or Beetle (`pivotTypes`) within that fraction of the blade length from the pivot kills it outright, CRACK!), Stork Snips nick (`critZone`; its `weakAlways` gives every graded hit the Lamp's `lampMult`), Ribbon Shears curl (`curlSec`: every Ribbon snip drops a curl of ribbon on the nearest road point within a blade length, pooled in `state.curls` (`curlMax`), slowing enemies within `curlPx` to `curlSlow` x speed until it fades; bosses and airborne Moths ignore it), Safety Firsts and Dagger Shears all +10%), the Pins' permanent tiers 120/240/450 per type (`pinTierCosts`; T1 build cost −15%, T2 ring +15%, T3 the type's signature, `pinSignature`; on sale once the Pin's level is cleared, seven Pins), Sharpen (40, per pair, see Sharpness below) and SHRED's tiers (120/240/400). Firsts outside a level get called out: the results card lists what a clear unlocked and the map plays the cards (SHRED's tiers after L3, a pair on its `shopAfter` level, a Pin's tiers on its `pinFrom` level) and the results card shows a line naming the first deal the balance covers that the player hasn't seen (meta.js `newDeals`, `Save.tips.shopSeen`); the Sewing Box's and the Shop's entrances carry a gold dot until every such deal has been seen on its tab; cosmetics: handle tint baked into the weapon art by weaponArt.js `setHandleTint`, blade glow drawn by render.js. `node tools/buttonsupply.js` prints the one-time supply, the wage by level and the sinks (in README).
- Sharpness (`CONFIG.meta.sharp*`, per pair in `Save.sharpness`, read with scissors.js `sharpness(id)`): 0 (dull) to 1 (sharp), `sharpStart` 0.5 for a pair never touched. Every snip attempt, hit or miss, wears it by `sharpWearPerSnip` (meta.js `wearBlade`; not in level 0), never on a clock. At a run's start game.js fixes `state.sharpMult` = `sharpDullMult`..`sharpSharpMult` by the edge (x1 at half, so the start is the balance point); every graded snip is multiplied by it (not fire, needles or SHRED). The edge is named in five bands (`sharpBands`: Dull, Worn, Fair, Keen, Sharp), each with a line under the meter on what the humans did with the pair that day (story.js `sharpen`; sharpMeter.js `.sm-note`). Sharpen (`buySharpen(id)`, `sharpenCost` Buttons) puts it back to 1, offered below `sharpenFrom`; from the Shop's Scissors tab or the weapon select screen. The run report carries `sharpness` (the edge at the start).
- Levels live in `src/levels/` (level 0, the five worlds' ten each, `random`; `CONFIG.defaultLevel`), loaded only through `loadLevel`. `CONFIG.map.worlds` places them on the map (`docs/worlds.md` is the design contract: what each level introduces, the tools, enemies, bosses and rules per world; change it first). A level's `waves` and `startThread` default to CONFIG's (`levelWaves()` in game.js); `allowedPins` limits the picker further (on top of the progression). A win scores stars: 1 for clearing, +1 per `starRules` rule met (`noDamage`: nothing reached the workshop; `noSpecial`: no SHRED; `pin`: built a Pin; `critters`: every silverfish squished), recorded in the save and the run report. The goals are shown on the weapon screen (`#select-goals`, all still to play for; words in `CONFIG.starGoals`; the third star's goal, the level's feat, is highlighted), as a level starts only with Tomato's line (`#goals`, `CONFIG.starGoalsMs`) and on the pause card with how each stands this run (`starGoals()` in game.js: on / met / lost). Painted ones (`meadow`, `fork`) have `paths` (one or more routes, each walked first to last point, all ending on the heart pad), `spots`, `spotR`, `roadHalfWidth` and `workshopR`. With several routes an enemy picks one at random at spawn (`e.route`); routes simply overlap where the road is shared. `view.levelDef` (what `level()` returns) is the level as played.
- Level generator: a `recipe` entry (`hem`: `zigzag 2, fork pin`, `seed` 3) is built by levelGen.js and painted by levelArt.js; `random: true` (Random Quilt) gets a new `randomRecipe` from each run's seed in a zone from kit.js `randomZone` (startGame rebuilds it and main.js re-runs the resize chain through `setLevelHook`), so `?seed=` replays it. `?recipe=` adds a temporary `custom` level (`?world=` picks its zone; denim by default). Generated levels keep the plate size (941×1672), start at the top and end on the heart pad above the action bar; the road stays in `xMin..xMax` and pads in `spotXMin..spotXMax` so a 360px-wide phone (which crops the sides) still shows them. Recipes that don't fit get their last segments dropped, too-close roads and short pad counts are warnings (console, and in the lab).
- Progression (`CONFIG.pinFrom`, `CONFIG.shredFrom`, `CONFIG.skillFrom`): one new tool at a time, each beside the problem it answers, and every world follows the same beat sheet (1 the look and a new enemy, 2 the world's Pin, 3 a road twist, 4 pressure, 5 mini boss, 6 the reward in play, 7 the world's Skill, 8 two entrances, 9 the gauntlet, 10 boss; `docs/worlds.md`). Pins: Needle 1-1, Ice 1-6, Fire 2-2, Magnet 2-6, Cork 3-2, Lamp 4-2, Candle 5-2; SHRED 1-3. A tool is on every map level from its own on (`pinAllowed`, `shredAllowed`, `skillAllowed`, `moveAllowed` in game.js; a move slot whose move isn't allowed here is empty for the run: no badge, no charge); off the map once that level is cleared; `Save.unlocks.pins` (debug Unlock all) opens a Pin everywhere. On its first level a Pin's picker card says NEW, and the weapon screen says NEW HERE (the win card's Next level goes through the weapon screen for such a level). Weapons: Safety Firsts L0, Split Enders on sale after 1-2, Dagger Shears 1-10, Scrap Snippers after 2-2, War Nippers 2-10, Ratchet Pruners after 3-2, Kitchen Shears 3-10, Cigar Cutter after 4-2 (for the Beetles at 4-4), Stork Snips 4-10, Ribbon Shears after 5-2. A world's mini boss (level 5) puts the world's Pin's tiers on sale (world 1: SHRED's); its boss (level 10) opens the next world.
- Towers ("Pins" in the UI; `CONFIG.towers`) set up snips; the Fire and Needle Pins are the exceptions that deal damage. They can only stand on the level's spots (`level().spots`, one Pin each; `state.towers[i]` is spot i). Building: tap the + on an empty spot (the game pauses), then one of the Pins fanned out around it. The four cost the same, so the choice is about role. Every number a Pin plays by comes from pins.js `pinDef` (cached on the tower as `t.def`): the type's permanent tier (Sewing Box, Buttons) and the Pin's in-level rank (1..3, `t.rank`: tap a built Pin's gold II / III button, `rankUp(i)`, `rankUpCost` = `pinRanks.costMult[rank]` × the build cost in Thread; each rank widens the ring and multiplies the Pin's power; gone when the level ends, so leftover Thread has somewhere to go once the spots are full; `state.run.rankUps` in the report, `report.towers` stays the count built so the one-Pin / no-Pin achievements hold). Radii are in level units (`towerReachOf(t)` = px). Cork Pin (world 3): a trap on the road at the Pin's road point (`t.fx/fy`): when an enemy's road point comes within its ring it pops: everything within the ring stands stunned `stunSec` (`e.holdT`; no push-back) and a trap catches a given enemy only once (`e.corks`, a bit per Pin, as the Magnet's `e.magnets`), then it re-arms over `rearmSec` (drawn pressed flat, towerArt `drawCorkTrap`); tier 3 `popTwice` pops again `popSecondSec` later. Lamp Pin (world 4): enemies in its ring are `lit`: graded snips on them do `lampMult` x with a LIT! word (the Stork's `weakAlways` stacks on top), and in the night rule its whole ring counts as light (`isLit()`); tier 3 `lampCrit` adds a crit on lit enemies (the larger of the pair's crit and this, never both). Candle Pin (world 5): enemies in its ring are `soft` (`e.soft`, `softT`): armor is off (as slowed), Snowballs stop growing and shrink `meltShrinkPerSec` back toward their start size (never to death), graded snips do `meltMult` x (rank raises the bonus part; Icicles scale it by `iceFireMult`); bosses are never softened; tier 3 `meltLingerSec` keeps it soft after leaving. Ice Pin: enemies in its radius move at its `slowMult` (the strongest ring they're in; `iceSlow` by rank) and are `slowed`; a tier-3 Ice Pin also stops an enemy for `freezeSec` as it first steps in (`e.iced`). Fire Pin: enemies in its radius catch fire (`e.burning`, drawn with flames) and keep burning `burnSec` after leaving it, taking `burnDps` HP/s every `burnTickMs` (the strongest ring's numbers, `e.burnDps`; ignores armor; orange damage numbers). Burn kills score and pay thread but don't charge SHRED. Needle Pin (the archer): when reloaded and an enemy is in its radius, fires one needle at the one furthest along the road (`damage`; tier 3 a `volley` of two, the second at the next-furthest), then reloads for `cooldownSec`. Needles home on their target at `needleSpeed` level units/s (a needle whose target died flies on `needleLostSec`, then vanishes); armor stops one like a snip (the first hit on an unslowed Brute clangs, the armor is spent either way); kills score and pay thread but don't charge SHRED; silver damage numbers. Magnet Pin: every `periodSec` (each Pin drags a given enemy back only once, `e.magnets` bit per tower index, so nothing loops in its ring), tweens the road progress `u` of enemies in its radius back toward the anchor, `pullBack` ring radii up the road from the Pin's road point on their own route (`fu[route]`), leaving `pullKeep` of the gap on the stretch of road nearest the Pin and progressively more toward the ring's edge (`pullFalloff`; nothing at the edge; its aura fades the same way), so everyone loses ground, the ones ahead most, and lands in a clump that stands still for `holdSec` (`e.holdT`, as the Ratchet Pruners' jaw; `e.pulling` while the tween owns `u`/`ox`/`oy`; inOutSine; tagged by the enemy so a kill cancels it). Thread per level is tuned with `node tools/wavesheet.js` (its "spare" and "ranks" columns).
- Moves: two free move slots (`Save.moves`, `state.moves`; game.js "moves"), each holding SHRED (below) or any Skill the level allows, or nothing; the same move is never in both. SHRED is simply the first move the player gets (1-3); the Skills come one per world. Picked before a level on the weapon screen's Moves row (two slot chips, each opening a row of the allowed moves; skills.js `setMove`); a move's first level puts it in an empty slot, else the second (skills.js `giveMove`, from main.js `showLevelName`), says NEW HERE, and NEXT LEVEL detours through the weapon screen for it. At a run's start (`resetRun`) slot i takes `Save.moves[i]` if this level allows it (`pickMove`, `moveAllowed`), else stays empty; `slotOf[id]` finds a move's slot so every effect reads its own slot's numbers, and the code is the same for both slots. In play each slot has its round badge under the HUD wave badge (`#move-card-0`, `#move-card-1`, actionBar.js), filled by its move's own charge (`moveCharge`: each event adds 1/`need`; nothing builds while the effect is on, `moveBusy`), gold when full; a tap arms or fires it (`useMove(i)`), E fires slot 1 and F slot 2 (`keyMove`: SHRED spins at once while gripping, otherwise as a tap); only one slot is armed at a time (arming one disarms the other). Every charge event charges whichever slot holds the move it charges (SHRED's snip kills, Focus's clean snips, Mark's nicks, Pinking's multi-snips, Thimble's kills near the heart), so two Skills at once each run on their own meter and effects. Run reports carry `moves` (the two ids) and `moveUses`; `specialUses` stays SHRED's count (the `noSpecial` star).
- Skills (`CONFIG.skills`, `CONFIG.skillFrom`, `CONFIG.skillCosts` 120/240/400; src/skills.js `skillDef(id)` = the entry with its bought tier (`Save.skills[id]`, 0..3) applied, cached on its slot's `def` at a run's start): moves for either slot, one per world: Tailor's Focus 1-7, Thimble Guard 2-7, Seam Mark 3-7, Pinking Cut 4-7, Basting Stitch 5-7. Usable from its level on (`skillAllowed`), off the map once that level is cleared; bought up in the Sewing Box's Moves tab (meta.js `skillOpen` / `skillCost` / `buySkillTier`; `deals()` lists a Skill's next tier as `skill:<id>:<tier>`). Focus (charged by full-open snips that hit, `fullOpen`): fires at once; `update()` scales the world's dt by `focusSlow` for `focusSec` at the hit-stop gate while input, blade contact and the critters' opening check keep real time (SHRED's spin runs on the world clock, so it spins slower too); tier 3 refunds charge per kill. Thimble (kills within `thimbleNearPx` of the heart, squished silverfish x `fishCharge`): fires at once; a brass cap on the heart pad (`state.thimble` stops left) that pops the next `thimbleStops` enemies to reach the workshop with no damage, thread or kill (`reachWorkshop` asks `thimbleStop` first; mini bosses are bumped, the big bosses ignore it); tier 2 bumps them back `thimbleBumpU` instead. Mark (nicks that hit, and a snip that hits nothing with an enemy within `markNearPx`): armed, then the next press on an enemy chalk-marks it (`e.marked`); the next graded snip on it does `markMult` x and ignores armor (on an armored boss that replaces `armorDownMult`), then the mark is spent; tier 1 spreads the mark to neighbours within `markSpreadPx` when the marked one dies, tier 2 refunds charge on a marked kill, tier 3 allows two marks. Pinking (multi-snips): armed, then the next manual snip also cuts a zigzag lane `pinkingLen` past the tips, `pinkingW` wide (every enemy on it goes through `strike` at the tip grade); tier 2 pierces non-boss armor, tier 3 drops a slowing trail (`state.curls` with kind 'pinking'). Basting (no charge: pays `bastingCost` Thread per stitch, the badge dims and shows the price while short): armed, a press-and-drag across the road (input.js `pressX/Y`, `ptX/Y`, `ptDown`; snips are suppressed while sewing) sews a stitch line (`state.stitches`, max `bastingMax`) that holds the first `bastingHolds` enemies to reach it for `bastingSec` (`e.holdT`; not the big bosses), then frays; tier 3 held enemies take `bastingDmgMult` x. The `noSpecial` star stays about SHRED only. Sounds in sfx.js (`focusIn`, `thimble`, `chalk`, `pinking`, `basting`). Mark's and Basting's real touch gestures have only been driven by code so far.- Endless (Random Quilt, its level file's `endless: true`, `isEndless()` in game.js; tunables in `CONFIG.endless`): a bigger plate every run (the file's `size`, 1.8, passed to `randomRecipe`), waves generated from the run seed (`endlessWave(n)`, own mulberry stream; `planWaves` at the start, more as reached) without end: a boss alone every `bossEvery`th wave (the five in turn, `bossHpPerCycle` more hp and `bossEscortPerCycle` trailing Scraps each time round; `healAfterBoss` heart back once it's cleared; a mini boss (`minis`, in turn) mid-wave every `miniEvery`th non-boss wave from `miniFromWave`, driven by the wave number alone so seeds stay deterministic), else `groupsBase + groupsPerWave × (n − 1)` groups (max `groupsMax`) of a type drawn by weight among those unlocked by wave n (`types`), each `sizePerWave` bigger a wave. Enemies get tougher by wave only (`endless.hpPerWave`, the rank mix `rankPerWave` from `rankFromWave`). The HUD shows wave n/∞ and the run's kills; no stars (the weapon screen and pause card show the goal and the personal best); the run ends only when the heart falls ("SURVIVED n WAVES"), pays the wage however it ends, and keeps personal records in `Save.levels.random` (`bestWave`, `bestKills`, `bestScore`; the results note calls out a new best).
- Helicopter special (SHRED, from `CONFIG.shredFrom`; a move like the Skills, in whichever slot the player gave it, see Moves above): bought up with Buttons (`CONFIG.shredTiers`, `Save.skills.shred`, scissors.js `shredDef()`; meta.js `buyShred`, `shredCosts` 120/240/400, on sale once SHRED's level is cleared): Single Spin (1 turn, 25 kills) -> Double Spin (2 turns) -> Quick Charge (18 kills) -> Whirlwind (3 turns). Charged by `shredDef().charge` snip kills (its slot's `need`; not during a spin). Trigger: tap its full badge to arm it (its slot's `armed`), then the next press on the table (`go`, from input's `onPress`) starts it once the scissors are there; its slot's key (E / F) while gripping, or one more finger while gripping (the 2nd in Hold, the 3rd in Pinch), fires it at once. Its slot holds its charge and armed state; the spin itself (`state.heli`) is one at a time. Snaps open, spins `shredDef().turns` turns (`heliTurnMs` each), damages everything in blade reach every `heliTickMs` (ignores armor, slows), then snaps shut into a normal full-open snip. The hand moves the pivot but not spread or aim; normal snips are ignored while it runs.
- Run reports: `endGame` builds `lastReport` (seed, waves, score, snips, kills, accuracy, multi-snips, towers, specialUses (SHRED's), moves and moveUses (the two slots' moves and their uses), leaks, duration, userAgent, the six debug values, replay link) and saves it via runlog.js. Network traffic: the Random Quilt leaderboard (Supabase, `src/leaderboard.js`, only when a run is posted or the list is opened) and PostHog (`src/analytics.js`): anonymous `session_start` / `run_started` / `run_ended` events (no names, emails or person profiles; Settings has a Share play data switch) and the feedback card's `feedback_submitted` (sent only when the player presses SEND). Send feedback opens that card (`#feedback`, main.js); Email instead falls back to `FEEDBACK_URL`.
- Bosses (`CONFIG.bosses`, rules in game.js's bosses section, every entry with a `mode` and flags) come as the last wave of each world's level 10, alone: 1-10 The Seam Ripper (reward Dagger Shears), 2-10 The Brute King (War Nippers), 3-10 The Twine Ball (Kitchen Shears), 4-10 The Skeleton Key (Stork Snips), 5-10 The Unstitcher (the credits). Mini bosses (`mini: true`, about 2.5x an enemy, 10-16 HP) come mid-wave on each world's level 5 while spawns go on, with a short banner (`miniBannerMs`) instead of the intro card: 1-5 The Bobbin, 2-5 The Zipper, 3-5 The Honey Dipper, 4-5 The Bottle Cap, 5-5 The Snow Globe; each previews its world's boss. The wave opens on a two-line intro card (name + taunt, `bossIntroMs`) with the boss's own ZzFX roar, and the boss walks on as it closes; its HP bar runs across the top, with a rule line under it (`CONFIG.bossHints`, generic lines plus per-boss overrides, render.js `drawBossHint`): what to wait for in pale, gold when a snip will land. The taunts carry the story; the rule line carries the mechanics. Once the boss's HP drops to `bossTauntAt` its `taunt2` shows under the rule line for `bossTauntSec`. Modes (`bossMode(e)` reads the entry, `e.bdef`): `seam` (timing): walks the road back and forth (`bossTurns`, or `forward`); every `seamEverySec` its seam splits open for `seamOpenSec`: snips then do a flat `openDmg`, otherwise `closedDmg`; in Pinch (Expert) the closed-blade line must also cross the seam; `unlocks` (the Skeleton Key): on each turn its teeth are open and `unlockMoths` Moths come in by the level's side entrance; `shake` (the Snow Globe): every `shakeEverySec` it shakes for `shakeSec`: screen shake, every built Pin is snowed under (`t.snowedT`, off, a snow cap drawn by render.js) for `snowSec`, and only then do snips do `openDmg`. `armor` (timing + patience): armored and walking forward; every `chargeEverySec` it trembles inside a tightening red ring for `windupSec`, then charges `chargePx` along the road over `chargeSec`; the lunge knocks its thimble helmet off and it stands dazed for `armorDownSec`: snips do `armorDownMult` x graded damage, with the armor on they clang; `rolling` (the Bottle Cap, no helmet): speed bursts bouncing between the road's edges, hits clang while it rolls, it wobbles to a stop between bursts; `captures` (the Twine Ball): regular enemies it rolls over during a charge are wrapped and shield it (`e.bound`), cutting a wrapped enemy frees every enemy wrapped on that charge; its level brings it alone, so each wind-up drops `feedCount` stunned Scraps ahead of it (`feedType`, `feedAheadPx`). `swarm` (Unstitcher phase 1): its escort Scraps (`e.escortOf`, `e.escortSlot`, `swarmSize` kept `swarmGapPx` apart) hold up a shield that blocks every hit ("SHIELDED!"); cutting the last one drops it for `shieldDownSec`; while up, every `swarmEverySec` it refills empty places; `escortLine` + `noRefill` (the Zipper): five teeth follow in a line behind it, the head is shielded while a tooth lives; `captures` (the Honey Dipper): it spawns nothing, enemies within `stickPx` stick to it and ride along as its shield, a snip on it shakes one loose (an enemy freed can't be caught again for `unstickSec`). `trail` (the Bobbin): walks, and every `spoolEverySec` drops a Scrap behind it; kill it and they stop. The Unstitcher switches swarm -> armor -> seam (faster) at `phaseAt` (`phases`). Bosses can't be shoved or slowed (Ice, SHRED), their HP isn't scaled per wave, and fire / needles / SHRED are blocked where the mode blocks snips (`bossBlocks`). Random Quilt rotates every boss in turn.
- Kills of tier 2+ trigger a whole-world hit-stop (`hitStopMs`, boss `bossHitStopMs`). Input keeps running through it. Every kill adds screen shake proportional to the enemy's radius. Both run on game.js's real-time tween group, and fragment fades on the world group; a frame is frozen if `fx.hitStop` was still > 0 when it started.
- World zoom (`view.Z`, set by game.js `applyZoom` in `layout()`): a level with `size` > 1 is a bigger plate shown zoomed out, so the road, enemies, scissors, Pins, props and effects all shrink together and only the UI keeps its size. Everything in game.js, input's pose, scissors.js, critters.js and render.js's world drawing is in world px (the screen is W x H world px); render.js draws the world under a `dpr * Z` transform, then banners / boss bar / SHRED banner / pickups in screen px (SW/SH). Fingers are screen px: input.js divides the pose by Z, and the pivot offset stays in screen px so the blades clear real fingers. The weapon is sized from SH (`scaleFor`), so it shrinks with the world. Floating words and damage numbers keep their screen size (readability). DOM placed from world positions (Pin + buttons, the picker) multiplies by Z.
- The level is a painted plate (`level()`): drawn full height and centred, so level units → screen px is `view.L = H / level.h`, offset `view.LX`. Each of `level.paths` (in plate pixels, traced along the painted road) is rebuilt into a Catmull-Rom polyline on resize. Enemy radii and weapon reach are still in screen px, not level units. Levels with several entrances (`level().entries`, `entryOf`): each spawn draws its entrance in `beginWave` (so its arrow can warn `entryWarnSec` first: `state.entryMarks`, drawn by render.js `drawEntryMarks`), then `pickRoute` picks among that entrance's routes (weighted by `pathW`). A boss always takes the longest route (`longestRoute`, by `lenU`) and comes in by its entrance. Enemies walk at a steady speed, not in a fixed time: `traverseSec` is for a road `CONFIG.traverseRefLen` plate units long (`path.lenU`), so a longer road takes longer (level 0 keeps its fixed time). Enemies store progress `u` (0..1) along their route and advance at `speed` (`1 / traverseSec` scaled as above). Shoves are an offset (`ox`, `oy`) that springs back to the road at `pathReturnRate`, capped at `level.roadHalfWidth` from the centreline (`keepOnRoad`), so nothing can be shoved off the road.
- An enemy reaching the workshop deals its size `tier`. The heart pad at the end of the road shows the HP (a number on the heart, damage stages as it drops); there is no HP counter in the HUD. A kill scores the size's `score`, times `multiSnipMult` when the snip's zone held at least `multiSnipMin` enemies (survivors count toward that).
- Snips, too-slow shakes and blade contact only happen in PLAYING / WAVE_CLEAR / TUTORIAL.
- Level 0 ("First Snip", `CONFIG.tutLevel`, mode TUTORIAL) is a no-text tutorial for Hold (easy) controls: `setEasyOnly` forces Hold whatever the setting, Safety Firsts, one straight road, no Pins / thread / SHRED / HUD / HP number, no floating words, and nothing hurts the heart (a Scrap that reaches it just counts as done). A ghost hand (`state.tut.ghost`, drawn by render.js) demonstrates each step, repeating every `tutGhostCycleMs` and holding longer and bigger each repeat (`tut.rep`); it hides while the player presses and returns `tutGhostReturnMs` after a lift that didn't pass. Steps: 1 touch; 2 hold `tutHoldSec` until the blades open (a ring fills round the finger), then lift; 3 cut three frozen Scraps (they walk into empty blades); 4 a row of six (the ghost shows one wide cut; the step passes once the row is gone, however it was cut); 5 `tutFinishCount` (3) Scraps walk the road; once each is cut or through, it's cleared. Every step ends on the first success, so nothing loops. A small skip arrow skips a step. Clearing it sets `tutorialDone`, records the level (its reward, Safety Firsts, queues the map's reveal) and opens the MAP. PLAY goes straight to level 0 until `tutorialDone`; How to play and patch 0 on the map replay it.
- Sound: every sound is triggered from game.js through audio.js; the AudioContext is resumed on the first menu-button click.

## Rules

- **Buttons come only from playing: never from a clock, a streak, a purchase or a chance roll. Earning may be unbounded (every win pays the wage), but every source is visible before the run starts, pays the same for the same play on any day, and costs nothing to skip. No login rewards, limited-time stock, timed chests or loot boxes. Stars are never purchasable. Pins are unlocked by progression and never sold; only their tiers are bought. Scissors are either a map level's reward or bought in the Shop with Buttons, never with anything else.**
- **Never put a cooldown on the base snip; the player's fingers are the cooldown.**
- **Critters yield Thread only, at a fixed amount, are never targetable by pins, and are capped per level. Never add a critter whose reward is random or whose spawn is on a real-time clock.**
- **All tunable numbers live in `src/config.js`, each with a one-line comment,** except level data, which lives in `src/levels/` (one file per level, loaded through `loadLevel`). Modules read `CONFIG` at runtime, so the debug panel can change values live. Don't copy config values into module-level constants.
- **No npm, no bundler, no CDN. Third-party code is vendored into vendor/ with its license, and must be under 5KB each.** Plain ES modules via `<script type="module">`, no build step.
- **The scissors' cutting zone must never be occluded by the player's fingers; blades extend away from the finger midpoint.** The pivot sits `pivotOffsetPx` above the finger midpoint, and the blades point perpendicular to the finger line, away from the hand.

## Conventions

- Hot loop: no per-frame allocations. Entities are pooled (`on` flag); snip history is a typed-array ring buffer.
- Snip detection reads the raw finger spread; rendering reads the smoothed `pose`. A close that started wide open (≥ `snipOpenFrom`) but took longer than `slowLookbackMs` still reports "too slow" (tracked by `openPeak` in input.js) instead of being ignored.
- Debug panel: long-press the top-right corner for 1.5s. "Reset defaults" restores `config.js` values and clears localStorage. If feel seems off, check the panel for a stale override first.
