# Battle Scissors

A 2D mobile canvas game prototype built around one mechanic: the player's fingers work a pair of scissors that snip whatever sits between the blades. Touch has two control modes (Settings on the title): **Hold** (default, easy: hold one finger to open, lift to snip) and **Pinch** (two fingers are the handles, a fast pinch snips).

## Running

Double-click `Play.bat`, or run:

```bash
node tools/serve.js
```

It serves on port 8000 on all interfaces, opens http://localhost:8000 (with `--open`), and prints a LAN address for testing on a phone on the same Wi-Fi. If 8000 is busy it moves up to the next free port (8001, 8002, ...). `python3 -m http.server` also works. ES modules don't load from `file://`, so opening `index.html` directly shows a "use Play.bat" message. Desktop controls (mouse, wheel, Space, A/D rotate, E = SHRED, P/Esc = pause, R) are listed at the top of `index.html`. `?seed=1234` pins the run seed and `?level=fork` picks the level (the run report's replay link carries both). `?recipe=s,fork pin` plays a generated road (see Level generator below). The level lab, `/tools/level-lab.html` on the dev server, previews recipes.

Shared runtime state lives in exported objects (`state` in game.js, plus `input`, `view`, `weapon`, `cut`), because ES modules can't reassign each other's `let` bindings. `state` holds the mode, wave, HP, score, seed, stats, effect timers (`state.fx`), the road polylines (`state.paths`, one per route of the level), the thread balance, `heli` (special), `tut` (onboarding step), `run` (report counters), `events` (a 32-entry ring of one-off happenings for the renderer: `thread` pickups, `place`) and the entity pools (`enemies`, `frags`, `parts`, `labels`, `nums`, `pops`, `needles`, and `towers`, one per spot of the current level, rebuilt by `setLevel`; plus `critters` and `splats`, owned by critters.js): plain objects with an `on` flag and no methods. Each frame, `update()` calls `updateInput()` first, so snips resolve before timers and entities advance; then `draw(state)` paints.

**game.js contains no canvas calls. All drawing lives in render.js. This keeps a future Phaser/Godot port cheap.** (render.js calls the art helpers enemyArt.js, towerArt.js and weaponArt.js; game.js, input.js and scissors.js never draw.)

Seeds: every run gets `state.seed` (`Date.now()` by default; `?seed=1234` in the URL pins it for every run). Gameplay randomness uses mulberry32 streams from that seed: `rng.spawn` (enemy variation, and which route each enemy takes on a multi-route level; single-route levels draw nothing for it), `rng.hit` (shove chance), `rng.fx` (fragment bursts), `rng.critter` (critter schedule and lanes). They're separate so spawns don't depend on how many hits happened. Only purely visual sparkle (particles) may use `Math.random`. The seed shows in the debug panel and on the game-over card.

## Game flow

`TITLE -> MAP | SETTINGS | level 0 (TUTORIAL -> MAP), MAP -> SELECT -> PLAYING -> WAVE_CLEAR (waveClearMs) -> PLAYING ... -> GAME_OVER`. On the title, PLAY opens the level MAP (tap a numbered patch; BACK returns to the title), which opens SELECT for the weapon (it names the level; START begins, BACK returns to the map); How to play replays level 0; the gear opens SETTINGS (touch controls Hold/Pinch, Sound, Vibration; BACK returns); the Sound icon toggles mute; the title's Shop tile opens the Shop (tabs: Scissors = the inventory, equip, upgrades, Sharpen and the pairs for sale; Moves = SHRED's tiers and skills to come; Style = cosmetics; BACK returns to the title); the Shop and Trophies also open from the map's top-left row, beside the Buttons balance. Random Quilt (title, once level 0 is cleared) and Custom Road are off the map: their weapon screen BACK, the results card's small button (Title) and the pause card lead to the title, not the map, and a won quilt offers NEW QUILT. Level 0 (TUTORIAL, see below) replaces the old text coach: PLAY opens it instead of the map until it has been cleared once. GAME_OVER covers both outcomes: losing (workshop HP hits 0) and winning (after the last entry in `CONFIG.waves`), shown with different headers. The card plays the results (results.js: stars, the Button tally by source, total, unlock reveal) and then shows one big button for the obvious next step (NEXT LEVEL on a win with a next patch, `nextLevelId()`, same weapon; CONTINUE to the MAP on a win without one; TRY AGAIN on a loss) with the others small underneath (Map, Play again). Pause (`state.paused`, not a mode; `state.pauseCard` = `menu`, `pins` or `build` (the Pin picker: no card) picks which card shows): the ⏸ button, P/Esc, or hiding the tab during PLAYING / WAVE_CLEAR / TUTORIAL. `update()` returns immediately while paused (no input, timers, tweens or clock), event-driven hooks (taps, E, Space) are ignored, paused time is excluded from the run duration, and resuming re-arms snip detection. The pause card offers RESUME, Back to map, Sound on/off and Quit to title (leaving a run mid-way sends it as a `quit`). Send feedback lives in Settings only (plus the credits card and the Shop's skill ideas). Quit to title, the game-over Reset (home) tile and the R key return to TITLE; START and Play Again call `startGame()` with the current weapon.

- Weapons live in `CONFIG.weapons`: SVG geometry (`viewW/viewH/pivotX/pivotY/bladeLen/maxOpenDeg`, taken from the art) plus gameplay (`reachFrac` = on-screen blade length as a fraction of screen height, `damageMult`, `openMs` = how long a held mouse button or Hold-mode finger takes to open it fully). `view.S = reachFrac * weaponScale * H / bladeLen`. Blade opening, cut-zone width and reach, and blade-contact size all come from the current weapon. `maxOpenDeg` is half the cut zone's angle at full open; `aimOffsetDeg + aimOffsetOpenDeg × open` turns the whole art so an off-centre gap lines up with the aim (Ratchet Pruners). `kind: 'slide'` (Cigar Cutter): no pivot or blade angle; the cut zone is a circle of radius `bladeLen` at the hole, graded from its centre; closing blades don't shove; the boss seam line runs across the hole; SHRED reaches `spinLen`; the weapon card shows Hole and "guillotine" instead of Reach and Spread.

- Waves come from `CONFIG.waves`: one array per wave of `[type, count, atSec]` entries, with group members spaced by the type's `gapMs`. A spawn waits if the enemy pool is full. If every enemy is dead mid-wave, the wave clock skips ahead so the next spawn is at most `emptyWaveWaitSec` away (group spacing is untouched, since the skip only happens while the board is empty).
- Enemy types live in `CONFIG.enemyTypes`: scrap (groups, 1 HP), runner (small and fast, 1 HP; from level 3), bolster (3 HP), brute (6 HP plus armor; from level 5), beetle (the Button Beetle, 10 HP, level 11: `fireImmune`, `flat` = no weak spot, every snip does tip damage; `ringExecute` = a Cigar Cutter snip with its centre in the hole kills it outright), and the bosses seamRipper, bruteKing, unstitcher. Early levels bring types in slowly with fewer waves (L1-L2 Scraps and Bolsters, 3 waves); each level file lists its own waves. Snip damage is graded and must stay that way: `damageAtPivot` (2) down to `damageAtTip` (1), times the opening power (`powerAtMinOpen`..1), times `weakDamageMult` for a nick. So base HP equals snips needed at worst (a full-open snip at the tips). Each wave after the first scales every enemy's HP by `hpPerWave` (wave n = base × (1 + hpPerWave × (n − 1)); the tutorial's wave 0 uses base HP), so later enemies need hits nearer the pivot or an extra snip. Each map level from `hpLevelFrom` (3) on also adds `hpPerLevel` × the type's `levelHp` (Bolster, Brute 1; Scrap, Beetle 0.5; Runner 0) to that multiplier, so L12's Bolsters start at 2x; Random Quilt / Custom Road count as level `hpOffMapLevel`. Enemy ranks (`CONFIG.enemyRanks`, game.js `rankMix` / `drawRank`, `e.rank` 1..3): from L4 a wave spawn (not a boss, its escorts or level 0) may come as rank 2 or 3 of its type: its own colours (`enemyRanks.colors`, a sprite per rank in enemyArt.js), `hpMult` more HP, a touch faster (`speedMult`), more score (`scoreMult`; thread is the same). The mix grows per level and per wave: rank 2s phase in from L4 until the rank 1s are gone (about L9), then rank 3s phase in the same way.
- Brute armor: the first snip clangs for 0 damage unless `e.slowed` is true (Ice Pin aura, or a recent Helicopter hit).
- Thread (tower currency, in-level only, gone when the level ends): `startThread`, +`threadPerKill` per kill (a level file may set its own `startThread` / `threadPerKill`), +`threadPerLeak` when an enemy reaches the workshop, +30 per squished silverfish. Each map level's kill yield is trimmed so squishing every critter gives the pre-critter total and squishing none leaves it 60-120 short (`node tools/wavesheet.js`).
- Critters (`CONFIG.critters`, src/critters.js): bonus targets only a manual snip hits (not SHRED's spin or its final snap; Pins never see them, they aren't in `state.enemies`). No HP, not in waves, never reach the workshop, no penalty for escaping. Per level cap (`critters: { silverfish: n }`: World 1 2, World 2 3, World 3 4). Seeded (`rng.critter`), each due at a random moment of a boss-free wave's window (after `minWaveSec`); a due one waits while fewer than `minEnemies` are on screen or a boss seam is warning/open. Silverfish: crosses edge to edge in `crossSec` (2.3s) on a wobbling line off the road; blades *opening* within `skitterPx` make it turn a random `skitterMinDeg`..`skitterMaxDeg` off its line, toward the middle of the screen `skitterInward` of the time (the other way only if the burst stays on screen), and burst for `skitterSec` (once per crossing); a squish = 30 thread, the `squish` sound, a splat fading over `splatSec`, a gold "+30" flying to the counter. L02 (`critterIntro`) scripts its first one into wave 1's first lull (the wave clock holds while it crosses), and its third star is `starRules.critters` (every silverfish that came was squished). Run reports carry `critterKills` / `critterSpawns`; `Save.critterKills` counts all runs for the "Squish 25" achievement.
- Buttons (meta currency, `CONFIG.meta`, meta.js; never converted to or from thread): the wage on every win, floor(score/100) capped at `scoreCapBase + scoreCapPerLevel × level number` (L1 8, L13 32; replays pay it every time, so income never runs out; Random Quilt pays it as level `hpOffMapLevel`; `bonusPaid` keeps the level's best for the card); stars 10/15/25 the first time each is earned; achievements (achievements.js) once each; a world chest (three-star every level of a world, then tap it on the map: 100 + a cosmetic); stars, achievements and chests only on the map. Spent in the Shop (shop.js: new things only) on the Shop scissors (200-500 each, `CONFIG.weapons[id].shop`) and cosmetics; in the Sewing Box (sewingBox.js, tabs by armory.js: what you hold) on upgrades 150/300/600 per weapon (T1 +15% reach, T2 +20% close speed, T3 the weapon's `signature` stat +30%: Split Enders angle, War Nippers damage, Scrap Snippers crit (`critZone`/`critMult`), Ratchet Pruners jaw hold (`holdSec`: its hits hold regular enemies still), Cigar Cutter ring (`ringScale`), Safety Firsts and Dagger Shears all +10%), the Pins' permanent tiers 120/240/450 per type (`pinTierCosts`; T1 build cost −15%, T2 ring +15%, T3 the type's signature, `pinSignature`; on sale once the Pin's level is cleared), Sharpen (40, per pair, see Sharpness below) and SHRED's tiers (120/240/400). Firsts outside a level get called out: the results card lists what a clear unlocked and the map plays the cards (SHRED's tiers after L3, a pair on its `shopAfter` level, a Pin's tiers on its `pinFrom` level) and the results card shows a line naming the first deal the balance covers that the player hasn't seen (meta.js `newDeals`, `Save.tips.shopSeen`); the Sewing Box's and the Shop's entrances carry a gold dot until every such deal has been seen on its tab; cosmetics: handle tint baked into the weapon art by weaponArt.js `setHandleTint`, blade glow drawn by render.js. `node tools/buttonsupply.js` prints the one-time supply, the wage by level and the sinks (in README).
- Sharpness (`CONFIG.meta.sharp*`, per pair in `Save.sharpness`, read with scissors.js `sharpness(id)`): 0 (dull) to 1 (sharp), `sharpStart` 0.5 for a pair never touched. Every snip attempt, hit or miss, wears it by `sharpWearPerSnip` (meta.js `wearBlade`; not in level 0), never on a clock. At a run's start game.js fixes `state.sharpMult` = `sharpDullMult`..`sharpSharpMult` by the edge (x1 at half, so the start is the balance point); every graded snip is multiplied by it (not fire, needles or SHRED). The edge is named in five bands (`sharpBands`: Dull, Worn, Fair, Keen, Sharp), each with a line under the meter on what the humans did with the pair that day (story.js `sharpen`; sharpMeter.js `.sm-note`). Sharpen (`buySharpen(id)`, `sharpenCost` Buttons) puts it back to 1, offered below `sharpenFrom`; from the Shop's Scissors tab or the weapon select screen. The run report carries `sharpness` (the edge at the start).
- Levels live in `src/levels/` (the 13 map levels, `meadow`, `fork`, `hem`, then ten recipe levels up to `lair`; plus `random`; `CONFIG.defaultLevel`), loaded only through `loadLevel`. `CONFIG.map` places them on the map. A level's `waves` and `startThread` default to CONFIG's (`levelWaves()` in game.js); `allowedPins` limits the picker further (on top of the progression). A win scores stars: 1 for clearing, +1 per `starRules` rule met (`noDamage`: nothing reached the workshop; `noSpecial`: no SHRED; `pin`: built a Pin, L1's third star since SHRED isn't there yet), recorded in the save and the run report. The goals are shown on the weapon screen (`#select-goals`, all still to play for; words in `CONFIG.starGoals`; the third star's goal, the level's feat, is highlighted), as a level starts only with Tomato's line (`#goals`, `CONFIG.starGoalsMs`) and on the pause card with how each stands this run (`starGoals()` in game.js: on / met / lost). Painted ones (`meadow`, `fork`) have `paths` (one or more routes, each walked first to last point, all ending on the heart pad), `spots`, `spotR`, `roadHalfWidth` and `workshopR`. With several routes an enemy picks one at random at spawn (`e.route`); routes simply overlap where the road is shared. The waves are the same on every level. `view.levelDef` (what `level()` returns) is the level as played.
- Level generator: a `recipe` entry (`hem`: `zigzag 2, fork pin`, `seed` 3) is built by levelGen.js and painted by levelArt.js; `random: true` (Random Quilt) gets a new `randomRecipe` from each run's seed (startGame rebuilds it and main.js re-runs the resize chain through `setLevelHook`), so `?seed=` replays it. `?recipe=` adds a temporary `custom` level. Generated levels keep the plate size (941×1672), start at the top and end on the heart pad above the action bar; the road stays in `xMin..xMax` and pads in `spotXMin..spotXMax` so a 360px-wide phone (which crops the sides) still shows them. Recipes that don't fit get their last segments dropped, too-close roads and short pad counts are warnings (console, and in the lab).
- Progression (`CONFIG.pinFrom`, `CONFIG.shredFrom`): one new tool at a time, each beside the problem it answers. Needle Pin L1, SHRED L3 (the first four-wave level, with the Runners), Ice Pin L5 (with the Brute), Fire Pin L7 (the Denim), Magnet Pin L9 (four roads; sets up the Unstitcher's multi-snips). A tool is on every map level from its own on (`pinAllowed`, `shredAllowed` in game.js; `state.shredOn` per run hides the SHRED meter and stops its charge); off the map once that level is cleared; `Save.unlocks.pins` (debug Unlock all) opens a Pin everywhere. On its first level a Pin's picker card says NEW, and the weapon screen says NEW HERE (the win card's Next level goes through the weapon screen for such a level). Weapons: Safety Firsts L0, Split Enders on sale after L2, Dagger Shears L4, Scrap Snippers after L6, War Nippers L8, Cigar Cutter after L10 (for L11's Beetles), Ratchet Pruners after L11.
- Towers ("Pins" in the UI; `CONFIG.towers`) set up snips; the Fire and Needle Pins are the exceptions that deal damage. They can only stand on the level's spots (`level().spots`, one Pin each; `state.towers[i]` is spot i). Building: tap the + on an empty spot (the game pauses), then one of the Pins fanned out around it. The four cost the same, so the choice is about role. Every number a Pin plays by comes from pins.js `pinDef` (cached on the tower as `t.def`): the type's permanent tier (Sewing Box, Buttons) and the Pin's in-level rank (1..3, `t.rank`: tap a built Pin's gold II / III button, `rankUp(i)`, `rankUpCost` = `pinRanks.costMult[rank]` × the build cost in Thread; each rank widens the ring and multiplies the Pin's power; gone when the level ends, so leftover Thread has somewhere to go once the spots are full; `state.run.rankUps` in the report, `report.towers` stays the count built so the one-Pin / no-Pin achievements hold). Radii are in level units (`towerReachOf(t)` = px). Ice Pin: enemies in its radius move at its `slowMult` (the strongest ring they're in; `iceSlow` by rank) and are `slowed`; a tier-3 Ice Pin also stops an enemy for `freezeSec` as it first steps in (`e.iced`). Fire Pin: enemies in its radius catch fire (`e.burning`, drawn with flames) and keep burning `burnSec` after leaving it, taking `burnDps` HP/s every `burnTickMs` (the strongest ring's numbers, `e.burnDps`; ignores armor; orange damage numbers). Burn kills score and pay thread but don't charge SHRED. Needle Pin (the archer): when reloaded and an enemy is in its radius, fires one needle at the one furthest along the road (`damage`; tier 3 a `volley` of two, the second at the next-furthest), then reloads for `cooldownSec`. Needles home on their target at `needleSpeed` level units/s (a needle whose target died flies on `needleLostSec`, then vanishes); armor stops one like a snip (the first hit on an unslowed Brute clangs, the armor is spent either way); kills score and pay thread but don't charge SHRED; silver damage numbers. Magnet Pin: every `periodSec`, tweens the road progress `u` of enemies in its radius back toward the anchor, `pullBack` ring radii up the road from the Pin's road point on their own route (`fu[route]`), leaving `pullKeep` of the gap on the stretch of road nearest the Pin and progressively more toward the ring's edge (`pullFalloff`; nothing at the edge; its aura fades the same way), so everyone loses ground, the ones ahead most, and lands in a clump that stands still for `holdSec` (`e.holdT`, as the Ratchet Pruners' jaw; `e.pulling` while the tween owns `u`/`ox`/`oy`; inOutSine; tagged by the enemy so a kill cancels it). Thread per level is tuned with `node tools/wavesheet.js` (its "spare" and "ranks" columns).
- Skills to come (`CONFIG.skillIdeas`: Tailor's Focus L6, Thimble Guard L7, Pinking Cut L9, Seam Mark L10, Basting Stitch L12): placeholders only, shown in the Shop's Moves tab for playtest feedback; nothing in play reads them. The plan is two move slots: SHRED plus one of these, picked on the weapon screen before a level, each on its own charge and bought up in tiers.
- Helicopter special (SHRED, from `CONFIG.shredFrom`): a skill bought up with Buttons (`CONFIG.shredTiers`, `Save.skills.shred`, scissors.js `shredDef()`; meta.js `buyShred`, `shredCosts` 120/240/400, on sale once SHRED's level is cleared): Single Spin (1 turn, 25 kills) -> Double Spin (2 turns) -> Quick Charge (18 kills) -> Whirlwind (3 turns). Charged by `shredDef().charge` snip kills (not during a spin). Trigger: tap the full SHRED meter to arm it (`heli.armed`), then the next press on the table (`heli.go`, from input's `onPress`) starts it once the scissors are there; E, or one more finger while gripping (the 2nd in Hold, the 3rd in Pinch), fires it at once. Its charge meter is the SHRED meter under the HUD hearts. Snaps open, spins `shredDef().turns` turns (`heliTurnMs` each), damages everything in blade reach every `heliTickMs` (ignores armor, slows), then snaps shut into a normal full-open snip. The hand moves the pivot but not spread or aim; normal snips are ignored while it runs.
- Run reports: `endGame` builds `lastReport` (seed, waves, score, snips, kills, accuracy, multi-snips, towers, specials, leaks, duration, userAgent, the six debug values, replay link) and saves it via runlog.js. The only network traffic is PostHog (`src/analytics.js`): anonymous `session_start` / `run_started` / `run_ended` events (no names, emails or person profiles; Settings has a Share play data switch) and the feedback card's `feedback_submitted` (sent only when the player presses SEND). Send feedback opens that card (`#feedback`, main.js); Email instead falls back to `FEEDBACK_URL`.
- Bosses (`CONFIG.bosses`, rules in game.js's bosses section) only come on boss levels, as the last wave alone: L4 Seam Ripper (reward Dagger Shears), L8 Brute King (War Nippers), L12 The Unstitcher (credits). The wave opens on a two-line intro card (name + taunt, `bossIntroMs`) with the boss's own ZzFX roar, and the boss walks on as it closes; its HP bar runs across the top, with a rule line under it (`CONFIG.bossHints`, render.js `drawBossHint`): what to wait for in pale, gold when a snip will land ("Armor down: SNIP NOW!"). The taunts carry the story (the Seam Ripper is a drawer tool gone bad, the Brute King is stuffed with the player's cuttings, the Unstitcher waits past the back seam); the rule line carries the mechanics. Once the boss's HP drops to `bossTauntAt` its `taunt2` shows under the rule line for `bossTauntSec` (pale purple, wrapped in two near its middle when too wide for the screen). Each tests one skill, by mode (`bossMode(e)`): `seam` (timing): walks the road back and forth (`bossTurns`); every `seamEverySec` its seam splits open for `seamOpenSec` (a shimmer before, a chirp as it opens): snips then do a flat `openDmg`, otherwise `closedDmg`; in Pinch (Expert) the closed-blade line must also cross the seam (`seamHitTolPx` of the arc) or it does `expertOffSeamDmg`. `armor` (timing + patience): armored and walking forward; every `chargeEverySec` it trembles inside a tightening red ring for `windupSec` (a growl), then charges `chargePx` along the road over `chargeSec` (a speed burst, not a jump); the lunge knocks its thimble helmet off (it tumbles to the ground beside it over `helmFlySec`, landing `helmLand` away, alternating sides; `e.helmPh`, enemyArt.js `drawLooseHelmet`) and it stands dazed, stars circling its head, for `armorDownSec` (seams glow), picking the helmet back up over the last `helmPickupSec` and walking on: snips do `armorDownMult` x graded damage, with the armor on they clang. `swarm` (Unstitcher phase 1): its escort Scraps (`e.escortOf`, `e.escortSlot`, `swarmSize` of them kept `swarmGapPx` apart around it) hold up a shield that blocks every hit ("SHIELDED!"); cutting the last one, by any means, drops it for `shieldDownSec` (`e.shieldDownT`; snips do `shieldDownMult` x graded damage, its seams glow), then it comes back with a fresh swarm. While up, every `swarmEverySec` it refills empty escort places. The Unstitcher switches swarm -> armor -> seam (faster) at `phaseAt`. Bosses can't be shoved or slowed (Ice, SHRED), their HP isn't scaled per wave, and fire / needles / SHRED are blocked where the mode blocks snips (`bossBlocks`).
- Kills of tier 2+ trigger a whole-world hit-stop (`hitStopMs`, boss `bossHitStopMs`). Input keeps running through it. Every kill adds screen shake proportional to the enemy's radius. Both run on game.js's real-time tween group, and fragment fades on the world group; a frame is frozen if `fx.hitStop` was still > 0 when it started.
- World zoom (`view.Z`, set by game.js `applyZoom` in `layout()`): a level with `size` > 1 is a bigger plate shown zoomed out, so the road, enemies, scissors, Pins, props and effects all shrink together and only the UI keeps its size. Everything in game.js, input's pose, scissors.js, critters.js and render.js's world drawing is in world px (the screen is W x H world px); render.js draws the world under a `dpr * Z` transform, then banners / boss bar / SHRED banner / pickups in screen px (SW/SH). Fingers are screen px: input.js divides the pose by Z, and the pivot offset stays in screen px so the blades clear real fingers. The weapon is sized from SH (`scaleFor`), so it shrinks with the world. Floating words and damage numbers keep their screen size (readability). DOM placed from world positions (Pin + buttons, the picker) multiplies by Z.
- The level is a painted plate (`level()`): drawn full height and centred, so level units → screen px is `view.L = H / level.h`, offset `view.LX`. Each of `level.paths` (in plate pixels, traced along the painted road) is rebuilt into a Catmull-Rom polyline on resize. Enemy radii and weapon reach are still in screen px, not level units. Levels with several entrances (`level().entries`, `entryOf`): each spawn draws its entrance in `beginWave` (so its arrow can warn `entryWarnSec` first: `state.entryMarks`, drawn by render.js `drawEntryMarks`), then `pickRoute` picks among that entrance's routes (weighted by `pathW`). A boss always takes the longest route (`longestRoute`, by `lenU`) and comes in by its entrance. Enemies walk at a steady speed, not in a fixed time: `traverseSec` is for a road `CONFIG.traverseRefLen` plate units long (`path.lenU`), so a longer road takes longer (level 0 keeps its fixed time). Enemies store progress `u` (0..1) along their route and advance at `speed` (`1 / traverseSec` scaled as above). Shoves are an offset (`ox`, `oy`) that springs back to the road at `pathReturnRate`, capped at `level.roadHalfWidth` from the centreline (`keepOnRoad`), so nothing can be shoved off the road.
- An enemy reaching the workshop deals its size `tier`. The heart pad at the end of the road shows the HP (a number on the heart, damage stages as it drops); there is no HP counter in the HUD. A kill scores the size's `score`, times `multiSnipMult` when the snip's zone held at least `multiSnipMin` enemies (survivors count toward that).
- Snips, too-slow shakes and blade contact only happen in PLAYING / WAVE_CLEAR / TUTORIAL.
- Level 0 ("First Snip", `CONFIG.tutLevel`, mode TUTORIAL) is a no-text tutorial for Hold (easy) controls: `setEasyOnly` forces Hold whatever the setting, Safety Firsts, one straight road, no Pins / thread / SHRED / HUD / HP number, no floating words, and nothing hurts the heart (a Scrap that reaches it just counts as done). A ghost hand (`state.tut.ghost`, drawn by render.js) demonstrates each step, repeating every `tutGhostCycleMs` and holding longer and bigger each repeat (`tut.rep`); it hides while the player presses and returns `tutGhostReturnMs` after a lift that didn't pass. Steps: 1 touch; 2 hold `tutHoldSec` until the blades open (a ring fills round the finger), then lift; 3 cut three frozen Scraps (they walk into empty blades); 4 a row of six (the ghost shows one wide cut; the step passes once the row is gone, however it was cut); 5 `tutFinishCount` (3) Scraps walk the road; once each is cut or through, it's cleared. Every step ends on the first success, so nothing loops. A small skip arrow skips a step. Clearing it sets `tutorialDone`, records the level (its reward, Safety Firsts, queues the map's reveal) and opens the MAP. PLAY goes straight to level 0 until `tutorialDone`; How to play and patch 0 on the map replay it.
- Sound: every sound is triggered from game.js through audio.js; the AudioContext is resumed on the first menu-button click.

## Rules

- **Buttons come only from playing: never from a clock, a streak, a purchase or a chance roll. Earning may be unbounded (every win pays the wage), but every source is visible before the run starts, pays the same for the same play on any day, and costs nothing to skip. No login rewards, limited-time stock, timed chests or loot boxes. Stars are never purchasable. Pins are unlocked by progression and never sold; only their tiers are bought. Scissors are either a map level's reward or bought in the Shop with Buttons, never with anything else.**
- **Never put a cooldown on the base snip; the player's fingers are the cooldown.**
- **Critters yield Thread only, at a fixed amount, are never targetable by pins, and are capped per level. Never add a critter whose reward is random or whose spawn is on a real-time clock.**
- **All tunable numbers live in `src/config.js`, each with a one-line comment,** except level data, which lives in `src/levels/` (one file per level, loaded through `loadLevel`). Modules read `CONFIG` at runtime, so the debug panel can change values live. Don't copy config values into module-level constants.
- **No npm, no bundler, no CDN. Third-party code is vendored into vendor/ with its license, and must be under 5KB each.** Plain ES modules via `<script type="module">`, no build step.
- **The scissors' cutting zone must never be occluded by the player's fingers; blades extend away from the finger midpoint.** The pivot sits `pivotOffsetPx` above the finger midpoint, and the blades point perpendicular to the finger line, away from the hand.

## Conventions

- Hot loop: no per-frame allocations. Entities are pooled (`on` flag); snip history is a typed-array ring buffer.
- Snip detection reads the raw finger spread; rendering reads the smoothed `pose`. A close that started wide open (≥ `snipOpenFrom`) but took longer than `slowLookbackMs` still reports "too slow" (tracked by `openPeak` in input.js) instead of being ignored.
- Debug panel: long-press the top-right corner for 1.5s. "Reset defaults" restores `config.js` values and clears localStorage. If feel seems off, check the panel for a stale override first.
